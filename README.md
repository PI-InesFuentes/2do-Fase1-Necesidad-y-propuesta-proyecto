# Fase 1 · Análisis de la necesidad y propuesta del proyecto

**Proyecto Intermodular · 2º DAW · Inés Fuentes Martínez**

Primera fase de **Nudo**, una aplicación web para pequeños talleres de manualidades y artesanía (cerámica, pintura, velas, resina, labores...) que conecta la reserva de plazas con el stock del material que consume cada plaza.

En esta fase se analiza el sector, se identifica la necesidad, se revisan las soluciones existentes y se presenta la propuesta inicial.
